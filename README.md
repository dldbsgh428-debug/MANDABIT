# HABITUS

> 반복이 취향이 되고, 취향이 내가 된다.

**아비투스의 일곱 자본에 시간을 어떻게 쓰는지 기록하는 폰 앱.**

할 일을 지우는 앱이 아니라, 오늘 한 일이 **어느 자본에 쌓였는지** 보여주는 앱입니다.
점수도 레벨도 없습니다. 세는 것은 실제로 있었던 일뿐입니다 — 몇 번 했는가, 예정한 것 중
얼마를 했는가, 며칠째 이어지는가.

기록은 전부 기기 안에만 저장됩니다. 계정도, 서버도, 구독료도 없습니다.

---

## 폰에 설치하기

배포된 주소를 폰 브라우저로 연 다음:

- **안드로이드 (크롬)** — 앱이 띄우는 `설치하기` 버튼을 누르거나, 메뉴 → *앱 설치*
- **아이폰 (사파리)** — 아래 **공유** → **홈 화면에 추가**

설치하면 홈 화면에 아이콘이 생기고, 주소창 없이 전체 화면으로 열리며,
**인터넷이 없어도 그대로 동작합니다.**

### 배포

`main`에 올라가면 GitHub Actions가 자동으로 GitHub Pages에 배포합니다
(`.github/workflows/deploy.yml`). 저장소 설정에서 한 번만 켜 주세요:

**Settings → Pages → Source → GitHub Actions**

서비스 워커는 https에서만 뜨기 때문에, 설치형으로 쓰려면 이 배포가 필요합니다.
로컬에서는 `localhost`도 보안 컨텍스트로 쳐주므로 `npm run preview`로 확인할 수 있습니다.

## 일곱 자본

아비투스는 반복된 실천이 몸에 밴 성향입니다. 도리스 메르틴이 정리한 일곱 축을
앱 전체의 뼈대로 씁니다.

| 자본 | 한 줄 | 자라는 방식 |
|---|---|---|
| 🧠 심리자본 | 흔들려도 돌아오는 힘 | 명상, 감사, 회복 루틴 |
| 💪 신체자본 | 몸이 곧 지구력 | 운동, 수면, 식단, 자세 |
| 📚 지식자본 | 아는 만큼 보인다 | 독서, 공부, 기록 |
| 💰 경제자본 | 선택할 수 있는 자유 | 가계부, 저축, 투자 점검 |
| 🎨 문화자본 | 취향은 오래 남는다 | 전시, 음악, 영화, 요리 |
| 🤝 사회자본 | 관계는 저절로 자라지 않는다 | 먼저 연락, 모임, 도움 주기 |
| 🗣️ 언어자본 | 말이 곧 태도 | 글쓰기, 외국어, 발표 |

## 화면 넷

### 오늘
그날 예정된 실천 목록. 누르면 체크되거나, **도구가 붙어 있으면 입력창이 올라옵니다.**
줄에는 오늘 쌓인 것이 바로 보입니다 (`23,500원` · `5/8잔` · `45분`).
아래에 컨디션 이모지와 한 줄 기록.

### 자본
자본별 `지금까지 n회 / 최근 한 주 n회 / 예정한 것의 n%`, 비중 막대, 누적 실천 곡선,
요일별 달성률. 기간 필터(7·30·90일)는 모든 카드에 함께 적용됩니다.
**가계부 요약**도 여기 있습니다.

### 계획
주간 날짜 띠 + 하루 타임블록. 블록마다 자본을 붙이면 **그 하루를 자본별로 몇 시간씩
배분했는지** 보여줍니다. 기본 틀 넣기 / 어제 것 가져오기 지원.

### 더보기
실천 관리(추가·수정·순서·보관·삭제), 도구 지정, 테마, JSON 백업·복원, 초기화.

## 앱이 거드는 방법

실천을 체크만 하고 정작 그 일은 다른 앱에서 해야 한다면 그 습관은 오래 못 갑니다.
실천마다 도구를 붙일 수 있습니다.

| 도구 | 하는 일 |
|---|---|
| 💳 **가계부** | 금액·분류·메모를 적으면 기간별로 정리해 줍니다 |
| ＃ **횟수 세기** | 물 8잔처럼 목표까지 +1씩 |
| ⏱ **시간 재기** | 운동 30분처럼 걸린 시간을 누적 |
| ✎ **글 남기기** | 감사 일기, 감상, 연락한 사람 |
| ✓ **체크만** | 도구 없이 했는지만 표시 |

목표치가 있는 도구는 목표를 채워야 완료, 없으면 한 건만 적어도 완료입니다.
완료 여부는 기록을 넣고 뺄 때 자동으로 맞춰집니다.

## 계산 규칙

기록 앱은 숫자가 정직해야 쓸모가 있습니다.

- **하루 달성률** = 그날 *예정된* 실천 대비 한 것. 요일이 맞지 않으면 분모에서 빠집니다.
- **만들기 전 날짜**도 그 실천의 분모에서 빠집니다.
- **연속**은 예정이 없던 날을 건너뛰되 끊지 않습니다. 오늘이 아직이면 어제부터 셉니다.
- **삭제**하면 과거 기록과 그 실천으로 적은 가계부까지 사라집니다. 남기려면 **보관**을 쓰세요.
- 0~100 짜리 종합 점수는 만들지 않았습니다. 지어낸 한 숫자보다 비중 막대와 실제 횟수가 정직합니다.

## 색

자본 일곱 색은 색각 이상 시뮬레이션으로 검증했습니다 (인접쌍 CVD ΔE 9.1 라이트 / 8.4 다크,
일반 시야 19.6 / 19.3). 라이트 모드에서 대비 3:1을 넘지 못하는 색이 셋 있어 **색 옆에는 항상
이름표**가 붙습니다. 모든 차트에 **표로 보기**가 있어 값이 색에만 갇히지 않습니다.
다크 모드는 라이트를 뒤집은 것이 아니라 다크 배경 기준으로 따로 고른 색입니다.

## 실행

```bash
npm install
npm run dev        # 개발 서버
npm run build      # 타입 체크 + 프로덕션 빌드 (서비스 워커 포함)
npm run preview    # 빌드 결과 미리보기 — 설치·오프라인은 여기서 확인
```

## 구조

```
src/
├── types.ts              도메인 타입 (자본, 실천, 도구, 기록, 계획 블록)
├── data/
│   ├── capitals.ts       일곱 자본 — 팔레트 슬롯과 1:1로 묶여 있음
│   ├── tools.ts          도구 메타, 가계부 분류, 금액·시간 표기
│   └── presets.ts        온보딩 후보 실천, 기본 타임블록
├── lib/
│   ├── date.ts           로컬 타임존 기준 날짜 유틸 (toISOString 미사용)
│   ├── stats.ts          횟수·달성률·연속 — 위의 계산 규칙이 여기 다 있음
│   ├── entries.ts        도구 기록 읽기, 가계부 집계
│   └── store.ts          useSyncExternalStore + localStorage
├── components/
│   ├── ui.tsx            Card · Bar · TableView 등 공용 조각
│   ├── charts.tsx        직접 그린 SVG 차트 (차트 라이브러리 없음)
│   ├── ToolSheet.tsx     도구 입력창 (가계부·횟수·시간·글)
│   ├── MoneyCard.tsx     가계부 요약
│   └── InstallPrompt.tsx 홈 화면에 추가 안내
└── screens/              Today · Capitals · Plan · More · Onboarding
```

런타임 의존성은 React뿐입니다. 차트도, 날짜 계산도, 상태 관리도 직접 만들었습니다.
