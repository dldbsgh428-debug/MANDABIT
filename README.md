# HABITUS

> 반복이 취향이 되고, 취향이 나가 된다.

**아비투스(habitus)를 중심에 둔 하루 계획표 + 습관 트래커.**
할 일을 나열하는 대신, 오늘 쓰는 시간이 **어떤 자본을 쌓는지**를 기록합니다.

브라우저에서 바로 쓰는 웹앱이며, 모든 기록은 기기의 `localStorage`에만 저장됩니다.
계정도, 서버도, 구독료도 없습니다.

---

## 왜 아비투스인가

아비투스는 반복된 실천이 몸에 밴 성향입니다. 도리스 메르틴은 그것을 일곱 가지
자본으로 정리했는데, HABITUS는 이 일곱 축을 앱 전체의 뼈대로 씁니다.
습관 하나하나에 자본을 붙여두면, 한 달 뒤 **내 아비투스가 어느 쪽으로 기울어
있는지**가 그래프로 드러납니다.

| 자본 | 한 줄 | 자라는 방식 |
|---|---|---|
| 🧠 심리자본 | 흔들려도 돌아오는 힘 | 명상, 감사일기, 회복 루틴 |
| 💪 신체자본 | 몸이 곧 지구력 | 운동, 수면, 식단, 자세 |
| 📚 지식자본 | 아는 만큼 보인다 | 독서, 공부, 기록, 정리 |
| 💰 경제자본 | 선택할 수 있는 자유 | 가계부, 저축, 투자 점검 |
| 🎨 문화자본 | 취향은 오래 남는다 | 전시, 음악, 영화, 요리 |
| 🤝 사회자본 | 관계는 저절로 자라지 않는다 | 안부 연락, 모임, 도움 주기 |
| 🗣️ 언어자본 | 말이 곧 태도 | 글쓰기, 외국어, 발표 연습 |

## 화면

### 오늘
- **오늘의 만트라** — 날짜를 씨앗으로 고정 선택되는 한 줄 선언문. 직접 쓰거나 고정할 수 있습니다.
- **하루 계획표** — 시간 블록마다 어떤 자본을 키울지 태그합니다. 기본 틀 넣기 / 어제 계획 가져오기 지원.
- **오늘의 습관** — 그날 요일에 예정된 습관만 올라옵니다.
- **컨디션** — 이모지 하나. 한 달을 모으면 상태 곡선이 됩니다.
- **저녁 회고** — 잘한 것 / 배운 것 / 내일 가장 중요한 한 가지.

### 트래커
습관 × 날짜 월간 격자. 칸을 눌러 지난 날짜도 바로 체크할 수 있고, 행마다
달성률·현재 연속·최고 연속이 따라옵니다. 아래에 컨디션 이모지 행과 일별 달성률
스파크 막대, 주간 달성률 차트, 그리고 한 달을 닫는 세 문장(리뷰)이 붙습니다.

### 아비투스
- **자본 균형** — 7자본별 달성률 가로 막대. 가장 두터운 자본과 가장 얇은 자본을 짚어줍니다.
- **달성률 추이** — 일별 라인. 예정된 습관이 없던 날은 선을 끊어 0%로 오해하지 않게 했습니다.
- **요일별 평균** — 어느 요일에 루틴이 무너지는지.
- 기간 필터(최근 7일 / 30일 / 이번 달)는 모든 카드에 함께 적용됩니다.

### 습관 · 설정
습관 CRUD(자본 지정, 요일 반복, 실행 힌트, 순서, 보관/삭제), 테마(시스템·라이트·다크),
JSON 백업 내보내기/불러오기, 전체 초기화.

## 계산 규칙

기록 앱은 숫자가 정직해야 쓸모가 있어서, 분모를 이렇게 잡았습니다.

- **하루 달성률** = 그날 *예정된* 습관 대비 체크한 습관. 요일이 맞지 않는 습관은 분모에서 빠집니다.
- **아직 오지 않은 날짜는 어떤 분모에도 들어가지 않습니다.** 월 달성률은 오늘까지만 셉니다.
- **습관을 만들기 전 날짜**도 그 습관의 분모에서 빠집니다.
- **연속 달성(streak)** 은 예정이 없던 날을 건너뛰되 끊지 않습니다. 오늘이 아직 미완이면 어제부터 셉니다.
- **하루 평균**은 날짜별 비율의 평균, **누적 달성률**은 기간 전체를 한 분모로 묶은 값입니다. 둘 다 보여줍니다.
- 습관을 **삭제**하면 과거 체크 기록도 함께 지워집니다. 기록을 남기려면 **보관**을 쓰세요.

## 차트 원칙

- 자본 색은 **개체를 따라갑니다.** 값이 바뀌어도, 필터를 걸어도 심리자본은 계속 같은 파랑입니다.
- 7자본 팔레트는 색각 이상 시뮬레이션으로 검증했습니다 (인접쌍 CVD ΔE 9.1 라이트 / 8.4 다크,
  일반 시야 19.6 / 19.3). 라이트 모드에서 대비 3:1 아래인 색이 있어, **색 옆에는 항상 이름표**가 붙습니다.
- 모든 차트에 **표로 보기**가 있습니다. 값이 색이나 툴팁에만 갇히지 않습니다.
- 다크 모드는 라이트를 뒤집은 것이 아니라 다크 서피스 기준으로 따로 고른 색입니다.

## 실행

```bash
npm install
npm run dev        # 개발 서버
npm run build      # 타입 체크 + 프로덕션 빌드
npm run preview    # 빌드 결과 미리보기
```

`dist/`는 정적 파일이라 아무 정적 호스팅에나 그대로 올릴 수 있습니다.
`vite.config.ts`의 `base: './'` 덕분에 하위 경로에 배포해도 동작합니다.

## 구조

```
src/
├── types.ts                  도메인 타입 (자본, 습관, 하루 기록, 타임블록)
├── data/
│   ├── capitals.ts           7자본 정의 — 팔레트 슬롯과 1:1로 묶여 있음
│   ├── mantras.ts            만트라 프리셋 + 날짜 기반 선택
│   └── presets.ts            기본 습관 10개, 기본 타임블록, 컨디션 이모지
├── lib/
│   ├── date.ts               로컬 타임존 기준 날짜 유틸 (toISOString 미사용)
│   ├── stats.ts              달성률·연속·자본별 점수 — 위의 계산 규칙이 여기 다 있음
│   └── store.ts              useSyncExternalStore + localStorage, 외부 상태 라이브러리 없음
├── components/
│   ├── ui.tsx                Card · StatTile · Meter · TableView 등 공용 조각
│   ├── charts/               직접 그린 SVG 차트 (차트 라이브러리 의존성 없음)
│   ├── today/                만트라 · 타임블록 · 습관 체크 · 컨디션 · 회고
│   └── tracker/MonthGrid.tsx 월간 격자
└── pages/                    Today · Tracker · Insights · Habits · Settings
```

의존성은 React와 Tailwind뿐입니다. 차트도, 날짜 계산도, 상태 관리도 직접 만들었습니다.

## 데이터

브라우저 데이터를 지우기 전에 **설정 → JSON으로 내보내기**를 하세요.
