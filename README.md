# HABITUS

1억 모으기 프로젝트를 위한 자산관리 앱. React Native(Expo)로 만든 iOS·안드로이드 앱입니다.

가계부 앱이 아니라 **목표 달성 추적기**에 가깝습니다. 매달 얼마 썼는지보다
"이 속도면 1억까지 언제 도달하는가"를 첫 화면에서 답하는 것이 목적입니다.

## 핵심 기능

**목표 진척도 대시보드**
- 순자산 기준 달성률 링, 남은 금액, 전월 대비 증감
- 최근 순자산 증가 속도로 계산한 **예상 달성 시점** (기록이 부족하면 설정한 월 저축 목표로 대체)
- 목표 시한을 정하면 매달 필요한 저축액을 역산
- 월별 순자산 추이 라인 차트 + 현재 속도 추세선
- 월별 순자산 증가액 바 차트 (목표선 표시)
- 종류별 자산 구성 도넛 차트

**자산·부채 관리**
- 현금·예금·적금·주식·코인·연금·부동산 / 대출·카드값·전세대출
- 계좌별 잔액 업데이트 이력이 쌓이고, 그것이 순자산 추이 그래프의 데이터가 됨
- 계좌별 잔액 추이 차트
- 특정 계좌를 순자산 계산에서 제외 가능

**수입·지출 가계부**
- 날짜·카테고리·계좌·메모로 거래 기록 (어제/2일 전 빠른 선택)
- 월별 수입·지출·저축액과 **저축률** 자동 계산
- 카테고리별 지출·수입 비중 도넛 + 순위 목록

**월 저축 목표 · 예산**
- 월 저축 목표 달성률
- 카테고리별 월 예산과 소진율 (80% 주의 / 100% 초과 경고)

**데이터**
- 모든 데이터는 기기 안(AsyncStorage)에만 저장. 서버·로그인 없음
- JSON 파일로 백업 내보내기 / 복원

## 실행

```bash
npm install
npm start
```

터미널에 나오는 QR 코드를 [Expo Go](https://expo.dev/go) 앱으로 스캔하면 폰에서 바로 실행됩니다.

```bash
npm run android   # 안드로이드 에뮬레이터/기기
npm run ios       # iOS 시뮬레이터 (macOS 필요)
npm run web       # 브라우저에서 확인
```

### 검증

```bash
npm run typecheck   # tsc --noEmit
npm test            # jest
```

## 설계 노트

**순자산 추이는 잔액 기록에서 복원한다.** 계좌 잔액을 업데이트할 때마다
`BalanceSnapshot`이 쌓이고, 특정 월의 순자산은 "그 달 말일 이전의 가장 최근 기록"으로
계산합니다. 그래서 매달 잔액만 갱신해 두면 추이 그래프가 자동으로 그려집니다.
기록이 없는 기간은 그 계좌가 없었던 것으로 보고 0으로 처리합니다.

**예상 달성 시점은 실제 기록을 우선한다.** 최근 6개월의 순자산 증가 평균을 쓰고,
기록이 부족하거나 증가가 없으면 사용자가 설정한 월 저축 목표로 대체합니다.
둘 다 없으면 예측을 하지 않고 그렇다고 말합니다 — 근거 없는 숫자를 보여주는 것보다
정직하기 때문입니다.

**금액은 원 단위 정수로만 다룹니다.** 부동소수점 오차를 피하기 위해서입니다.
날짜도 `Date` 객체 대신 `'YYYY-MM-DD'` 문자열을 기본으로 써서 타임존 때문에
하루가 밀리는 문제를 없앴습니다.

**계좌를 삭제해도 가계부 내역은 남습니다.** 계좌 연결만 끊습니다.
카테고리도 이미 쓰인 것은 삭제 대신 숨김 처리합니다 — 실제로 지우면 과거 거래가
'미분류'로 변해 지난 달 통계가 망가지기 때문입니다.

**차트는 라이브러리 없이 `react-native-svg`로 직접 그렸습니다.** 필요한 모양이
네 가지(링·라인·바·도넛)뿐이고, 직접 그리면 다크 테마와 원화 단위 축 라벨을
정확히 맞출 수 있습니다.
