# 아이콘 만들기

앱 아이콘은 이미지 편집기 대신 스크립트로 그린다. 색이나 비율을 조금 바꿀 때
6개 파일(아이콘·파비콘·적응형 전경/배경·모노크롬·스플래시)을 손으로 다시
맞출 필요가 없다.

```
pip install pillow
cd tools/icon && python make_assets.py ../../assets
```

- `make_icon.py` — 그림 자체(동전 스택 + 새싹). 색과 비율이 여기 다 있다.
  직접 실행하면 비교용 변형(기본 / ₩ 없음 / 다크 배경 / 동전 계단)을 만든다.
- `make_assets.py` — 배경과 크기를 바꿔가며 assets/ 파일 6개를 뽑는다.

크기를 바꿀 땐 `finish(art, bg, fit=...)`의 `fit`만 건드리면 된다.
적응형 아이콘 전경은 기기마다 잘리므로 `SAFE`(0.62) 이하로 둔다.
