# 아이콘 만들기

앱 아이콘은 이미지 편집기 대신 스크립트로 그린다. 나중에 색이나 모양을
조금 바꿀 때 6개 파일(아이콘·파비콘·적응형 전경/배경·모노크롬·스플래시)을
손으로 다시 맞출 필요가 없다.

```
pip install pillow
python tools/icon/make_assets.py assets
```

- `make_jar.py` — 저금통 도형 자체. 색과 비율이 여기 다 있다.
- `make_assets.py` — 크기·배경·실루엣을 바꿔가며 assets/ 파일 6개를 뽑는다.

`make_jar.py`를 직접 실행하면 비교용 변형(글자 없음 / '모아' 글자 /
다크 배경) 세 가지를 현재 폴더에 만든다.
