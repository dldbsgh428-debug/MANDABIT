# 아이콘 만들기

앱 아이콘은 `source.jpg`(직접 만든 원본 그림) 한 장에서 스크립트로 뽑는다.
원본을 바꾸면 6개 파일(아이콘·파비콘·적응형 전경/배경·모노크롬·스플래시)이
한 번에 다시 만들어진다.

```
pip install pillow numpy
cd tools/icon && python make_assets.py ../../assets
```

- `from_source.py` — 원본에서 크림 사각형을 잘라내고, 배경을 걷어낸
  '내용물' 판을 만든다. 배경을 색으로만 거르면 금색 동전까지 딸려가서,
  테두리에서 번져 들어가는 방식으로 바깥을 따로 구한다.
- `make_assets.py` — 그걸 크기·배경별로 6개 파일로 저장한다.

바꿀 만한 값

- `SAFE`(0.66) — 적응형 아이콘 전경 비율. 기기마다 원/사각형으로 잘리므로
  이 밖으로 나가면 모서리가 잘린다.
- `from_source.TOL`(16) — 배경으로 볼 색의 허용 오차. 흰색과 크림은
  파랑이 19 차이라 이 값이 그 아래여야 둘이 갈린다.
